WAVE v1.4.1 - MIDI -> MATEMATICA -> COLORE -> MOVIMENTO

AVVIO OFFLINE CONSIGLIATO (WINDOWS)
1. Estrai l intera cartella Wave-v1.4.1.
2. Copia i tuoi file .mid o .midi nella cartella "midi".
3. Fai doppio clic su "APRI WAVE.bat".

APRI WAVE.bat ricrea automaticamente midi/library.js e midi/library.json leggendo tutti i MIDI presenti, quindi apre index.html.

NUOVO IN v1.4.1 - 8 SCENE
- Pure: geometria astratta / Polygon Pulse
- Ocean: onde stratificate / Wave Line
- Hills: profili di colline / Wave Line
- Desert: dune / Wave Line
- Bubbles: bolle generate dagli attacchi MIDI
- Birds: stormo stilizzato generato dalle note
- Galaxy: spirali, stelle e orbite
- Bloom: rosette armoniche / Harmonic Bloom

CONTROLLI VISIVI
- Colore: Musicale, Monocromatico, Gradiente, Spettro
- Scia: persistenza delle posizioni precedenti
- Glow: intensita dell alone luminoso
- AUTO: cambia scena automaticamente durante la riproduzione

CONTROLLI MUSICALI
- Tempo: velocita di riproduzione e movimento
- Intensita: volume, ampiezza, spessore, saturazione e glow
- Tonalita: trasposizione MIDI e spostamento cromatico
- Complessita: strati, petali, onde, elementi e simmetrie

CARICA MIDI
"Carica MIDI" continua a leggere direttamente qualunque file selezionato, anche se non e presente nella libreria.

ONLINE / NETLIFY
La build usa scripts/build-midi-list.js e ricrea automaticamente la libreria MIDI dai file presenti in midi/.

INTERFACCIA COMPATTA v1.4.1
- Visualizzatore piu panoramico per mantenere i controlli vicini all'animazione.
- Tempo, Intensita, Tonalita, Complessita, Scia e Glow disposti affiancati con slider verticali.
- Le 8 Scene sono sempre visibili in una griglia 4 x 2, senza scorrimento orizzontale.
- Selettore Colore integrato nel pannello controlli.
